# صور الأدوية من مواقع الشركات

أدوات تجمع صور العلب من المواقع الرسمية للشركات السورية، وتربطها بأصناف الكتالوج.
الناتج الحالي في `data/catalog-images/` (صور WebP + `manifest.json`).

## ما الذي تم

- المصدر: مواقع 17 شركة؛ أعطت 15 منها صوراً لأصناف في قائمة الوزارة: آسيا، ابن الهيثم، السعد، بحري، بركات، الفارس، دلتا، دومنا، راما، هيومن فارما، حماة، كيمي، يونيفارما، فيتا فارما، مسعود فارما (وبيوميد وعيسى ليستا في قائمة الوزارة). كل المواقع تسمح بالزحف (robots.txt) والطلبات كانت بطيئة ومتأنية.
- النتيجة: 1,871 صنفاً بصورة (من 13,044) بـ1,067 صورة، حجمها 28 ميغا.
- الربط حسب الاسم **داخل نفس الشركة**، بثلاث درجات ثقة (تُخزَّن في `imageMatch` على الصنف):
  - `exact`: نفس الاسم والعيار.
  - `brand`: صورة العلامة التجارية نفسها (الموقع لا يفصل العيارات). لوحة الأدمن تُظهر عليها «صورة تقريبية».
  - `fuzzy`: تطابق بالتهجئة أو بالتعريب (مواقع عربية مثل ابن الهيثم).
- شكل العلبة وحده لا يكفي: يُرفض أي ربط يخالف الشكل الدوائي (أقراص مقابل شراب مثلاً) أو العيار.
- الصور التي تتكرر بنفس البايتات تحت 4 أسماء مختلفة فأكثر (صورة «لا توجد صورة») تُهمل، والأصغر من 90 بكسل تُهمل.

## ربطها بالقاعدة (على السيرفر)

```bash
cd backend
MEDIA_DIR=/var/lib/feniq/media MEDIA_PUBLIC_URL=https://api.<الدومين>/media \
  npm run link-catalog-images -- ../data/catalog-images --dry-run   # تجربة بلا كتابة
MEDIA_DIR=... MEDIA_PUBLIC_URL=... \
  npm run link-catalog-images -- ../data/catalog-images             # الربط فعلاً
```

- لا يلمس صنفاً له صورة أصلاً (صورة رفعها الأدمن) إلا مع `--overwrite`.
- الملفات تُنسخ إلى `MEDIA_DIR/catalog/` بأسماء من محتواها، فالصورة المشتركة بين عبوات الصنف الواحد تُخزَّن مرة واحدة.
- يجب أن يُستورد الكتالوج أولاً (`prepare/` يبني الملفات من قائمة الوزارة).

## سحب صور شركة بطلبها

كل صنف يحفظ صفحة المصدر في `imageSourceUrl`. لإزالة كل صور شركة:

```js
db.productcatalogs.updateMany(
  { imageSourceUrl: /barakat-pharma\.com/ },
  { $set: { imageUrl: null, imageSourceUrl: null, imageMatch: null } }
)
```

## إعادة التشغيل (لما تحدّث الشركات مواقعها)

مجلد عمل فيه `agg.pkl` (من `prepare/build2.py`) و`img/`:

1. `cd img && python3 ../harvest/h_asia.py` وباقي `h_*.py` — كل واحد يكتب `<شركة>.json` (لكل موقع طريقته: واجهة WordPress، أو صفحات المنتجات، أو API الموقع نفسه).
2. `python3 match.py` — يكتب `best.pkl` ويطبع نسبة الربط لكل شركة.
3. `python3 download.py` ثم `python3 build_pack.py` — ينزّل الصور، يتحقق منها، يحوّلها إلى WebP (800 بكسل كحد أقصى) ويكتب `pack/`.
4. `python3 sheet.py exact 1 20` — يرسم لوحة عشوائية من الربط للمراجعة بالعين.

يحتاج: `pip install pillow pandas openpyxl`.
