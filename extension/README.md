# فينيق · لاقط الطلبيات (إضافة Chrome و Firefox)

الصيدليات بتبعت طلبياتها للمستودع على الواتساب بكلام حرّ: «٢ بخاخ سالبوتامول،
امبروكسول شراب 10+1، املاد 5». المستودع بينسخها بإيده وبيدوّر على كل صنف وبيحسب.
اللاقط بيعمل هالشي بكبسة:

1. على **واتساب ويب**: مرّر الماوس على رسالة الصيدلية واكبس «لقط الطلبية». بيجمع
   الرسالة مع الرسائل المتتالية من نفس المرسل.
2. بيطابق كل سطر بكتالوج المستودع، حتى لو الاسم مكتوب بالعربي والكتالوج لاتيني
   (مطابقة صوتية: امبروكسول = AMBROXOL). بيفهم الأرقام العربية، الكميات بالكلمات
   («تنين»، «علبتين»)، البونص (10+1)، والعيار (5 مغ) لحاله عن الكمية.
3. بيعلّم كل سطر: مطابق، راجِع، مو موجود، أو غير متوفر. بتصلّح الكمية أو الصنف بكبسة.
4. «حط الرد بالمحادثة» بيكتب رد مرتب بالأسعار والإجمالي بخانة الكتابة، وفيه دعوة
   للصيدلية تنزّل تطبيق فينيق. **الإرسال دايماً بإيدك.**
5. كل رد بينحفظ بسجل محلي، وبتقدر تصدّره CSV، أو تنسخ الطلبية كجدول لإكسل.

بأي صفحة تانية (إيميل، ملف، موقع): حدّد النص، كبسة يمين، «حوّل لطلبية فينيق»، أو
`Alt+Shift+F`.

## مصدر الكتالوج

- **حساب فينيق**: تسجيل دخول بحساب المستودع، بيسحب `GET /api/warehouse/products`
  (كل الصفحات) و`GET /api/exchange-rate` وبيحوّل `priceUsd` لليرة. ما بتنحفظ كلمة
  السر، بس الـtoken والـrefresh token.
- **من إكسل**: لصق أعمدة (مع سطر العناوين) أو ملف CSV. الأعمدة بتتعرّف لحالها بالعربي
  أو الإنكليزي.
- **تجريبي**: 420 صنف من `site/demo-catalog.json`، بلا أسعار.

## التثبيت للتجربة

```bash
node extension/build.mjs        # يطلّع dist/chrome و dist/firefox وملف zip لكل واحد
node --test extension/test/     # اختبارات محرّك المطابقة وقراءة إكسل
```

- **Chrome / Edge**: `chrome://extensions` ← شغّل «وضع المطوّر» ← «تحميل إضافة غير
  مضغوطة» ← اختر `extension/dist/chrome`.
- **Firefox**: `about:debugging#/runtime/this-firefox` ← «تحميل إضافة مؤقتة» ← اختر
  `extension/dist/firefox/manifest.json`. للتثبيت الدائم لازم ترفع
  `feniq-order-catcher-firefox-*.zip` على addons.mozilla.org (مجاني، ممكن «غير مُدرجة»
  للتوزيع المباشر).

## البنية

| الملف | الدور |
|---|---|
| `src/matcher.js` | تقطيع النص، الكمية والبونص والعيار، المطابقة الصوتية والترتيب. بلا اعتماديات. |
| `src/panel.js` | الدرج الجانبي (Shadow DOM)، التعديل، الرد، السجل. |
| `src/whatsapp.js` | زر «لقط الطلبية» فوق الرسائل، وإدخال الرد بخانة الكتابة. |
| `src/background.js` | الكبسة اليمين، الاختصار، والحقن عند الطلب (`activeTab`). |
| `src/sheet.js` | قراءة أعمدة إكسل/CSV. |
| `options.html`, `popup.html` | الإعدادات والسجل، والنافذة الصغيرة. |

الصلاحيات قليلة عن قصد: لا وصول دائم لكل المواقع. الإضافة بتقرأ واتساب ويب فقط،
وباقي الصفحات لما المستخدم يطلب (كبسة يمين، الأيقونة، أو الاختصار).
