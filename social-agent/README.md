# أيجنت فينيق لصفحات التواصل 🤖

أيجنت بيدير صفحة فينيق على **فيسبوك** وحساب **انستغرام**، وبتحكي معه **بالعربي عادي (شامي أو فصحى)** من **تلغرام**.

## شو بيعمل

- **بيكتب المنشورات**: «اعمل بوست عن ميزة المرتجعات وانشره بكرا الساعة 7 المسا». بيكتب النص، بيحط صورة (من عندك أو بيولّدها)، وبيبعتلك مسودة. **ولا شي بينزل قبل ما تضغط ✅**.
- **بينشر على فيسبوك وانستغرام سوا**، هلق أو بموعد.
- **بيحوّل صورك لمنشورات**: ابعتله صورة وقلّه «اعمل منها بوست للانستا». بيشوف الصورة وبيكتب عنها.
- **بيرد على التعليقات**: كل 5 دقايق بيشيك عالتعليقات الجديدة، بيفهمها (حتى باللهجة)، وبيجهّز رد:
  - وضع **مراجعة** (الافتراضي): كل رد بيوصلك لتوافق عليه أو تعدّله بكلمة («خليه أقصر»).
  - وضع **تلقائي** (`/mode`): بيرد لحاله عالأسئلة السهلة والمديح، بيخفي السبام والشتائم، وبيبعتلك الشكاوى وأسئلة العمولة والحساس.
- **الرسائل الخاصة** (ماسنجر وانستغرام): بيقراها وبيجهّز الرد (شوف «حدود» تحت).
- **بيتذكر شغلنا**: «تذكّر إنه عنا عرض توصيل مجاني هالشهر» ← بيستعملها بكل المنشورات والردود (`/brief`).
- **كل أحد مسا** بيقترح خطة منشورات للأسبوع، و**كل خميس مسا** بيبعت تقرير (متابعين، أحسن منشور، اقتراحات).
- بيعرف قواعد فينيق من `PRODUCT.md`: ما بيذكر العمولة أبداً، ما بيخترع أرقام أو شهادات، ما بيعطي أسعار أدوية أو نصائح طبية.

الأوامر: `/connect` ربط الصفحة · `/queue` المجدول · `/plan` خطة الأسبوع · `/inbox` التعليقات المعلقة · `/report` تقرير · `/mode` تلقائي/مراجعة · `/brief` الملاحظات · `/status` الحالة · `/invite` ضيف حدا من الفريق.

## التشغيل لأول مرة (مرة وحدة، تقريباً 15 دقيقة)

كل شي تاني جاهز ومجرّب. هدول الخطوات بس اللي بدها حسابك إنت:

### 1) بوت تلغرام (دقيقتين)
1. بتلغرام افتح **@BotFather** ← ابعت `/newbot`.
2. الاسم: `Feniq Agent` — المعرّف: أي اسم بينتهي بـ `bot` (مثلاً `feniq_social_bot`).
3. انسخ التوكن اللي بيعطيك ياه.

### 2) توكن Cloudflare (3 دقايق) — عندك حساب من قبل
1. افتح https://dash.cloudflare.com/profile/api-tokens ← **Create Token**.
2. جنب **Edit Cloudflare Workers** اضغط **Use template**.
3. تحت Permissions اضغط **+ Add more** ← `Account` ← `Workers AI` ← `Edit`.
4. **Account Resources**: Include ← حسابك. **Zone Resources**: All zones.
5. **Continue to summary** ← **Create Token** ← انسخه.

### 3) (اختياري بس منصح فيه) مفتاح Gemini — مجاني
بيخلي فهم العربي أحسن. من https://aistudio.google.com/apikey انسخ المفتاح الموجود عندك (نفس اللي بمشروع اليوتيوب) أو اعمل واحد جديد.
بدونه الأيجنت بيشتغل على Workers AI المجاني.

### 4) حط الأسرار بـ GitHub
بالريبو `feniq-backend` ← **Settings ← Secrets and variables ← Actions ← New repository secret**، وضيف:

| الاسم | القيمة |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توكن الخطوة 1 |
| `CLOUDFLARE_API_TOKEN` | توكن الخطوة 2 |
| `GEMINI_API_KEY` | (اختياري) مفتاح الخطوة 3 |

### 5) شغّل النشر
**Actions ← Deploy social agent** ← آخر تشغيل ← **Re-run all jobs**.
بعد دقيقتين، بصفحة التشغيل نفسها (**Summary**) بيطلعلك رابط تفعيل ← افتحه من موبايلك ← **Start**.
هيك صرت مالك البوت (الرابط بيشتغل لمرة وحدة).

### 6) اربط فيسبوك وانستغرام
بالبوت ابعت `/connect`، وهو بيمشي معك خطوة خطوة: إنشاء تطبيق بلوحة Meta، نسخ App ID و App secret، وتوليد توكن بـ Graph API Explorer.
إذا علقت بأي شاشة، **ابعتله صورة الشاشة** وبيقلك شو تكبس.
الأسرار اللي بتبعتها بيمسحها من المحادثة فوراً.

خلصت 🎉 جرّب: «اعمل بوست ترحيبي بفينيق».

## حدود لازم تعرفها

- **لازم تطبيق Meta يكون Live** (البوت بيذكرك). وهو بوضع التطوير المنشورات بتنشاف إلك بس.
- **إرسال الرسائل الخاصة** من الأيجنت بدو موافقة Meta على التطبيق (App Review + توثيق النشاط التجاري)، وهاد بياخد أيام. لحد ذلك الأيجنت بيقرا الرسائل (إذا Meta سمحت بالقراءة) وبيبعتلك الرد جاهز: بتضغط عليه بينسخ، وبتبعته من Meta Business Suite. **التعليقات والنشر شغالين من أول يوم.**
- **انستغرام بدو صورة** لكل منشور، ونسبتها بين 4:5 و 1.91:1. الفيديو والريلز مو مدعومين بهالنسخة.
- التعليقات بتنفحص كل 5 دقايق (مو لحظياً).

مجاني: Cloudflare Workers (الخطة المجانية)، Workers AI (حصة يومية مجانية للصور والنص)، Gemini (حصة مجانية)، تلغرام.

## للمطوّر

- **Cloudflare Worker** (`src/index.js`): يستقبل webhook تلغرام، يخدم الصور لـ Meta (`/m/<id>.jpg`)، و `/privacy` و `/data-deletion` و `/icon.jpg` للوحة Meta.
- **Durable Object واحد** (`src/agent.js`) فيه كل الحالة بـ SQLite: المستخدمين، الحسابات والتوكنات، المنشورات، الصور، التعليقات/الرسائل، ومهام الطابور. كل شغل يمر بطابور يُعالَج بالـ alarm، فالرد على تلغرام فوري والذكاء الاصطناعي على مهل.
- **cron كل 5 دقائق**: نشر المجدول، فحص التعليقات والرسائل، الخطة (أحد 18:00) والتقرير (خميس 20:00) بتوقيت دمشق، وتنظيف البيانات بعد 90 يوماً (كما تعد سياسة الخصوصية).
- **الذكاء الاصطناعي** (`src/llm.js`): Gemini (عدة موديلات) ← OpenAI ← Workers AI، ينتقل تلقائياً عند أي فشل. الصور من Workers AI (flux-1-schnell).
- **المعرفة** (`src/brief.js`) من `PRODUCT.md` والموقع، وملاحظات المالك تُلحق بها. التعليمات بـ `src/brain.js`.
- **Meta Graph API** `v25.0` (`src/meta.js`): توكنات صفحة دائمة من توكن مستخدم طويل الأمد، انستغرام عبر الصفحة المربوطة.
- **الأمان**: رابط تفعيل المالك، سر الـ webhook، ومفتاح `/setup` كلها مشتقة (HMAC) من توكن البوت. البوت لا يطيع إلا المالك والمدعوّين.
- **النشر**: `.github/workflows/social-agent.yml` (اختبارات ← workers.dev ← `wrangler deploy` ← الأسرار ← `/setup`).

```bash
cd social-agent && npm ci && npm test   # 26 اختبار، كل الخدمات الخارجية محاكاة
```
