# ملف مستودع معتوق (مجلس الإدارة)

مواد تعريف بفينيق لمجلس إدارة مستودع معتوق (تشرين الأول 2026). المدير يعرضها على
المجلس بغياب فريق فينيق، لهيك كل شي فيها لازم يشرح حاله.

| الملف | شو هو |
|---|---|
| `out/board-pack.pdf` | ملف مجلس الإدارة، A4، 6 صفحات: الملخص، كيف يعمل، لوحة المستودع ويونيفارما، مقترح التجربة والكلفة، أسئلة وأجوبة، جرّب بنفسك |
| `out/summary.pdf` | الصفحة الأولى لحالها (ملخص بصفحة واحدة) |
| `out/deck.pdf` | العرض التقديمي، 12 شريحة 16:9 |
| `out/deck.pptx` | نفس العرض باوربوينت، وتحت كل شريحة ملاحظات للمقدّم |

## المصادر

- `board-pack.html` و `deck.html` و `brand.css`: النصوص والتصميم (ألوان وخطوط `DESIGN.md`).
  ملاحظات المقدّم بـ `<aside class="notes">` داخل كل شريحة.
- `assets/shots/`: لقطات حقيقية من التطبيق ولوحة التحكم، من نسخة **محلية** فيها
  حساب توضيحي اسمه «مستودع معتوق» محمّل بكل أصناف يونيفارما (289) ومعتوق فارما (15)
  من قائمة وزارة الصحة (`data/catalog-images/REPORT.xlsx`)، وطلبيات من صيدليات وهمية.
  الأسعار توضيحية. ما في شي من هالبيانات على السيرفر الحقيقي.
- `assets/products/`: صور علب يونيفارما من `data/catalog-images` (مصدرها موقع الشركة).

## إعادة البناء

```bash
cd pitch/maatouk
PLAYWRIGHT_CORE=<مسار playwright-core> CHROMIUM_PATH=<مسار chromium> node render.js pack
PLAYWRIGHT_CORE=... CHROMIUM_PATH=... node render.js deck
python3 build_pptx.py        # يحتاج python-pptx و Pillow
```

## شروط تجارية لازم المالك يأكدها قبل الإرسال

- عرض الشريك المؤسس: بلا عمولة فينيق (1%) خلال الستين يوماً، وبانر مجاني.
- «لا اشتراك ولا رسوم تسجيل».
- مدة التجربة 60 يوماً بفرع واحد.
- وعد «إدارة الفروع من حساب واحد وحسابات للموظفين قبل التوسع» (غير مبنية بعد).
- الكلفة كما بالنظام: 4% خصم المنصة للصيدلية + 1% عمولة المنصة (`warehouse.model.js`).
