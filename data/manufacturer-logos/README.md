# لوغوهات شركات الأدوية

لوغو كل شركة من **موقعها الرسمي** (الصفحة الرئيسية للموقع)، مقصوصة ومرتّبة في مربع 512×512 WebP
على خلفية بيضاء موحّدة (بركات: خلفية كحلية لأن لوغوها أبيض)، حتى تظهر بنفس الحجم والوضوح
في الوضعين النهاري والليلي.

`manifest.json`: `[{ manufacturerAr, file, source }]` - الاسم القصير للشركة (نفس `manufacturerAr` بالكتالوج)،
اسم الملف داخل `images/` (هاش المحتوى)، وموقع الشركة المصدر.

## ربطها بالقاعدة

مرة وحدة (آمنة تعاد): Actions ← **Link manufacturer logos** ← Run workflow. أو يدوياً:

```bash
cd backend
npm run link-manufacturer-logos -- ../data/manufacturer-logos --dry-run   # تجربة بلا كتابة
npm run link-manufacturer-logos -- ../data/manufacturer-logos             # الربط فعلاً
```

- لا يلمس شركة لها لوغو أصلاً (لوغو رفعه الأدمن) إلا مع `--overwrite`.
- شركة غير موجودة بالقاعدة تُسجَّل وتُتجاوَز (ما بتنخلق شركة جديدة).
- يفحص جميع ملفات الحزمة قبل أي رفع أو كتابة؛ نقص أي ملف يوقف التشغيل برمز فشل.
- لو رفع الأدمن شعاراً أثناء التشغيل، يبقى شعاره ويُسجَّل التخطي في `changedDuringRun`.
- تشغيلات Workflow متسلسلة؛ الربط الفعلي يبقى يدوياً و`dry_run` مفعّل افتراضياً.

## الشركات بلا لوغو حقيقي

89 شركة بالكتالوج: 18 لوغو حقيقي (حقل `source` = موقعها)، و71 **لوغو مولَّد** (`"generated": true`، بلا `source`):
شكل ملوّن (دائرة/سداسي/معيّن/درع/مربع) فيه الحرف الأول، واسم الشركة تحته، بنفس المربع الأبيض.
توليدها: `tools/catalog-images/gen_manufacturer_logos.py` (يحتاج `pip install pillow` مع raqm، وخطوط التطبيق).

لما نلاقي لوغو حقيقي لشركة مولَّدة: بدّل ملفها بـ `images/` وسطرها بـ `manifest.json` (وشيل `generated`)،
وشغّل الربط مع `--overwrite` (انتبه: بيستبدل كل اللوغوهات الموجودة، فاستعمله بعد ما تتأكد إنو الأدمن ما رفع شي).
