# لوغوهات شركات الأدوية

لوغو كل شركة من **موقعها الرسمي** (الصفحة الرئيسية للموقع)، مقصوصة ومرتّبة في مربع 512×512 WebP
على خلفية بيضاء موحّدة (بركات: خلفية كحلية لأن لوغوها أبيض)، حتى تظهر بنفس الحجم والوضوح
في الوضعين النهاري والليلي.

`manifest.json`: `[{ manufacturerAr, file, source }]` - الاسم القصير للشركة (نفس `manufacturerAr` بالكتالوج)،
اسم الملف داخل `images/` (هاش المحتوى)، وموقع الشركة المصدر.

## ربطها بالقاعدة

مرة وحدة (آمنة تعاد): Actions ← **Link manufacturer logos** ← Run workflow. أو يدوياً:

```bash
cd backend
npm run link-manufacturer-logos -- ../data/manufacturer-logos --dry-run   # تجربة بلا كتابة
npm run link-manufacturer-logos -- ../data/manufacturer-logos             # الربط فعلاً
```

- لا يلمس شركة لها لوغو أصلاً (لوغو رفعه الأدمن) إلا مع `--overwrite`.
- شركة غير موجودة بالقاعدة تُسجَّل وتُتجاوَز (ما بتنخلق شركة جديدة).

## الشركات بلا لوغو

الأربعة اللي ما لقينا لهم موقع رسمي: كيمي، ابن زهر، فيتا فارما، مسعود فارما، وباقي الشركات الأصغر.
التطبيق بيرسم لهم الحرف الأول بدائرة ملوّنة لحد ما يرفع الأدمن لوغو من لوحة الويب.
لإضافة لوغو: ضيف صورة بـ `images/` وسطر بـ `manifest.json` وشغّل الربط.
